Happy Birthday page — plain HTML, CSS and JavaScript

1. Unzip this folder.
2. Double-click index.html to open it in your browser.

Everything works offline: no install, no internet needed.

To change things:
- index.html  -> the words on the page (name, message, "from Fahad")
- style.css   -> colors, sizes, animations
- script.js   -> the confetti and the wish list (add your own wishes in the "wishes" list)
- salman.png  -> his photo (replace the file with the same name to use a different picture)
